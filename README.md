# MiniWallet

MiniWallet is a simple digital wallet application that allows users to manage their balance and transactions.

## Features

- User registration
- User login and logout
- Wallet balance
- Top up wallet
- Transfer money
- Transaction history
- Responsive dashboard
- Laravel REST API
- React frontend
- MySQL database

## Tech Stack

### Backend
- Laravel
- PHP
- Laravel Sanctum
- MySQL

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router
- Lucide React
